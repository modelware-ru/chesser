# Программа для изучения шахматных партий

Программа обеспечивает
- создание новой партии
- проигрывание партии

## Структура хранения партии

Каждая шахматная партия хранится в отдельном текстовом файле в кодировке utf-8 с расширением ".chessgame"

В файле есть строки, друх типов:
- служебные
- ходы партии

Пустые строки игнорируются
Служебные строки начинаются со знака "#". В них хранится информация в виде:

```
# <Key>: <Value>
```

Key может принимать следующие значения:
- Black - кто играет черными
- White - кто играет белыми
- Place - место, где была сыграна партия
- Date - дата, когда была сыграна партия
- Note - краткое описание партии

Все Value являются строками и никак не интерпретируются.

В файле может не быть ни одной служебной записи.
Если в файле есть несколько записей с одним и тем же ключом, то выбирается последний

Ходы партии записываются в виде последовательности положений фигур на доске.

Все клетки шахматной доски имеют [буквенное значение](./doc/board.svg) от "0" для клеки a1 и до "}" для клетки h8.

Cостояние доски записывается в виде 32 символов.
Первые 16 символов относятся к белым фигурам, а оставшиеся 16 к черным.

Нумерация позиций начинается с 0.

Позиции с 0 по 7 относятся к белым пешкам.
Позиции с 8 по 9 относятся к белым слонам.
Позиции с 10 по 11 относятся к белым коням.
Позиции с 12 по 13 относятся к белым ладьм.
Позиции 14 - белый ферзь
Позиции 15 - белый король

Позиции с 16 по 23 относятся к черным пешкам.
Позиции с 24 по 25 относятся к черным слонам.
Позиции с 26 по 27 относятся к черным коням.
Позиции с 28 по 29 относятся к черным ладьм.
Позиции 30 - черный ферзь
Позиции 31 - черный король

Если фигура не присутствует на доске, то в соответствующей позиции находится символ " " (проблем)

Начальное состояние обычной шахматной партии имеет вид

89ABCDEF25160734mnopqrstwzv{u}xy

Строка файла с ходом партии имеет вид

```
<State> <Color> <Step>
[
<Note>
]
```

- State - Состояние доски
- Color - Цвет фигуры (W или B), которая сделала ход и привела к данному состоянию доски. Может отсутствовать, если это начальное состояние партии
- Step - ход, который привел к данному состоянию достки, записанный в шахматной нотации
- Note - комментарий к ходу, записанные в произвольном формате и ограниченный скобками "[" и "]".


## Функциональность

### Создание новой партии

Пользователь создает новую шахматную партию, опционально заполняет поля (служебные строки) и проигрывает партию делая допустимые ходы фигурами.
После создания партию можно сохранить в виде файла, с [данной структурой](#формат-хранения-данных).
Программа спрашивает имя сохраняемого файла.

### Проигрывание партии
Пользователь загружает шахматную партию, выбирает за кого он будет играть: за белых, черных или за обоих.
Пользователь делает ходы за выбранный цвет (или за всех).
Программа проверяет правильность сделанных ходов и не дает сделать не правильные, выводя сообщение об ошибке.
Программа может "подсказать" правильный ход, если пользователь попросит.
Программа после каждого сделанного хода выводит комментарии.

### Дополнительные требования

Все всплывающие подсказки выводить в специальное фиксированное поле над доской.

В верхнем меню сделать кнопку настройки, в которой устанавливать значение следующих опций:
- показывать информацию об игре (данные из служебных строк)
- показыывать комментарии к ходам
- показывать сыгранные ходы

В соответствии с этими настройками должны быть скрыты соответствующие данные.

Кнопка "Подсказка" может быть включена или выключена. Если она включена, то подсказка показывается всегда

## Реализация

Программа должна быть реализована для работы в браузере (на мобильном телефоне, на планшете и десктопе) без использования сервера.

Программа полностью написана на javascript.

Использовать технологии:

- [redom](https://redom.js.org/)
- bootstrap
- rollup

Файлы с шахматными фигурами находятся в [папке](./doc/figure/)

Сборку осуществлять на локальном компьютере.

Исходные файлы хранить в [папке](../main/client/src/)

Файлы package.json и другие служебные сохранять в [папке](../main/client/)

Результат сборки javascript сохранять в [папке](../main/server/www/js)

Файлы стилей сохранять в [папке](../main/server/www/css/)

Файлы c шрифтами сохранять в [папке](../main/server/www/fonts/)

В [папке](../main/server/) создать файл index.html, который будет подгружать все необходимые файлы для запуска приложения
