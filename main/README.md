# Chesser — программа для изучения шахматных партий

Работает в браузере без сервера: откройте `server/www/index.html`. Кнопке «Хранилище» нужен веб-сервер
(например, `cd server/www && python3 -m http.server`): при открытии из локального файла браузер может запретить чтение партий.

## Возможности

- **Новая партия** — заполните поля (Белые, Черные, Место, Дата, Описание), делайте ходы на доске
  (касание/щелчок по фигуре и клетке или перетаскивание), добавляйте комментарии к ходам.
  Навигация по ходам, отмена хода, переворот доски. **Сохранить** — запрашивает имя файла
  и скачивает файл `.chessgame`.
- **Открыть** — загрузка файла `.chessgame` и выбор: играть за белых, за черных, за обоих
  или редактировать. Ходы соперника выполняются автоматически; неверные ходы отклоняются
  с сообщением; кнопка «Подсказка» включается и выключается: пока она включена, на каждом вашем ходу
  ход партии подсвечивается на доске и записан в поле над доской (состояние запоминается в браузере); кнопка
  «Сделать ход» делает правильный ход за вас; после каждого хода выводятся комментарии, самые новые сверху.
- **Хранилище** — дерево партий из `server/www/games/games.json`; выбранная партия загружается так же, как через «Открыть».
- **Настройки** — переключатели «Показывать информацию об игре», «Показывать комментарии к ходам»,
  «Показывать сыгранные ходы», «Показывать подсказку, чей ход». Выключенные данные скрываются в обоих режимах: информация об игре —
  поля заголовка, карточка партии и имена игроков в окне загрузки; комментарии — поле комментария,
  панель комментариев и значки комментариев у ходов; ходы — список ходов; подсказка «чей ход» — строка состояния над панелью (итог партии показывается всегда). Настройки запоминаются в браузере.

Все подсказки и сообщения выводятся в фиксированное поле над доской, доска при этом не сдвигается.

Проверяются все правила: шах, рокировка, взятие на проходе, превращение пешки, мат и пат.
Превращённая пешка остаётся в своей позиции строки состояния; фигура превращения
определяется по записи хода (`e8=Q`, по умолчанию ферзь).

## Сборка

Требуется Node.js (проверено на v24).

```sh
client/build.sh            # npm install, тесты и сборка rollup
cd client && npm run watch # пересборка при изменениях
```

Результат: `server/www/js/app.js`, `server/www/css/`, `server/www/fonts/`; страница — `server/www/index.html`.

Исходники: `client/src/` (`chess/` — правила и формат файла, `ui/` — интерфейс на redom + bootstrap).
